함께 설치하면 좋은 도구 3가지

Git

바뀐 내용 비교·되돌리기 (검토 화면에 필요)

winget install --id Git.Git복사

Node.js

웹 프로젝트 실행·미리보기

winget install --id OpenJS.NodeJS.LTS복사

Python

자료 정리·자동화 스크립트

winget install --id Python.Python.3.14복사

명령어 입력이 어렵다면 Codex에게 “Git 설치해 줘”라고 부탁해도 돼요.

여기는 선택 사항입니다. Codex만으로도 오늘 실습은 충분하지만, 함께 깔아 두면 좋은 도구가 세 가지 있어요. Git은 바뀐 내용을 비교하고 되돌릴 때 쓰고, Codex 앱의 변경 검토 화면에도 필요합니다. Node.js는 웹 프로젝트를 실행하고 미리 볼 때, Python은 자료 정리나 자동화 스크립트에 씁니다. PowerShell에 오른쪽 명령을 붙여 넣으면 설치되고, 직접 하기 어려우면 Codex에게 “Git 설치해 줘”라고 부탁해도 됩니다. (약 2분)

PowerShell에 명령어 한 줄 붙여 넣기

1시작 메뉴에서 PowerShell 실행
2아래 명령을 붙여 넣고 Enter
3새 창에서 codex --version 확인
Windows PowerShell
복사설치 명령 · Node.js 없이 바로 설치돼요 · 업데이트할 때도 같은 명령powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
CLI 설치는 정말 한 줄이면 됩니다. 시작 메뉴에서 PowerShell을 검색해 실행하고, 아래 상자의 명령을 복사해 붙여 넣은 뒤 Enter를 누르세요. 이 설치 방법은 Node.js가 없어도 됩니다. 설치가 끝나면 PowerShell 창을 새로 열고 codex --version을 입력해 보세요. 버전 숫자가 나오면 성공입니다. 나중에 업데이트할 때도 같은 명령을 다시 실행하면 됩니다. (약 3분)

막혔을 때

자주 만나는 문제·질문 6가지

QNode.js부터 깔아야 하나요?
아니요! 앱과 공식 설치 명령은 Node.js 없이 설치돼요 · npm으로 설치할 때만 필요
Q‘winget’을 찾을 수 없어요
Windows 업데이트 후, Store에서 ‘앱 설치 관리자’를 업데이트
Q스크립트 실행이 막혔어요 (실행 정책 오류)
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 입력 후 다시 실행
Q안전장치(샌드박스) 설정이 실패해요
관리자 창에서 ‘아니요’를 눌렀다면 다시 시도 · 학교 PC는 전산 담당 부서에 문의
QGit 기능(변경 검토)이 안 보여요
winget install --id Git.Git 설치 후 앱 다시 시작
Q메뉴에 Codex가 안 보여요
Store › 다운로드에서 ChatGPT 앱 업데이트 · ‘ChatGPT Classic’ 앱이 아닌지 확인

그래도 안 되면? 오류 화면을 캡처해서 ChatGPT에게 “이 오류 어떻게 해결해?”라고 물어보세요.

실습하다 보면 자주 막히는 지점이 몇 군데 있어서 정리해 두었습니다. 먼저 가장 많이 받는 질문, “Node.js부터 깔아야 하나요?”입니다. 예전에는 npm으로 설치하는 방법이 많이 소개돼서 그렇게 알려진 건데, 지금은 앱도, 공식 설치 명령도 Node.js 없이 설치됩니다. Node.js는 npm으로 설치하거나 웹 프로젝트를 실행할 때만 있으면 돼요. winget이 없다고 나오면 윈도우 업데이트를 하고 Store에서 앱 설치 관리자를 업데이트하세요. 스크립트 실행이 막히면 실행 정책을 바꾸는 명령을 한 번 입력하면 됩니다. 안전장치 설정이 실패하는 경우는 대부분 관리자 창에서 ‘아니요’를 눌렀거나 학교 PC 보안 정책 때문이에요. 그리고 7월 통합 이후 예전 ChatGPT 앱은 ‘ChatGPT Classic’으로 이름이 바뀌었으니, Codex 메뉴가 안 보이면 새 ChatGPT 앱인지 확인해 주세요. (약 3분)

승인 모드 유지

개인정보 금지

수강생 이름·학번·성적은 입력하지 않아요.

AI가 만든 결과물도 마지막 확인은 교수님이 해요.

강의나 연구에 쓰실 때 꼭 지켜 주셨으면 하는 세 가지입니다. 첫째, Codex에게는 전용 폴더만 열어 주세요. 연구 데이터나 행정 문서, 개인 자료가 있는 폴더는 열지 않습니다. 둘째, 승인 모드를 유지하고, 바뀌는 내용을 읽어 본 뒤에 승인하세요. 셋째, 수강생 이름이나 학번, 성적 같은 개인정보는 입력하지 않습니다. 결국 AI가 만든 결과물도 마지막 확인은 교수님 몫이라는 점, 기억해 주세요. (약 2분)
